# Rail Fence Cipher

Aplikasi GUI (Python + tkinter) untuk enkripsi & dekripsi **Rail Fence Cipher** (cipher transposisi), dibuat untuk tugas Kriptografi (Cipher Klasik).

- Plainteks ditulis zig-zag pada `k` baris, cipherteks dibaca baris demi baris.
- Spasi dibuang sebelum enkripsi, jadi hasil dekripsi tidak mengandung spasi.
- Ada visualisasi zig-zag.
- Contoh: `CRYPTOGRAPHY AND DATA SECURITY`, k = 3 -> `CTAAAEIRPORPYNDTSCRTYGHDAUY`

## Cara menjalankan
```
python railfence_cipher.py
```
