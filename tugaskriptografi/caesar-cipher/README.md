# Caesar Cipher

Aplikasi GUI (Python + tkinter) untuk enkripsi & dekripsi **Caesar Cipher**, dibuat untuk tugas Kriptografi (Cipher Klasik).

- Enkripsi: `c = (p + k) mod 26`
- Dekripsi: `p = (c - k) mod 26`
- Fitur: enkripsi, dekripsi, brute force (semua kunci 0-25), salin hasil.
- Huruf besar/kecil dipertahankan; angka, spasi, dan tanda baca tidak diubah.
